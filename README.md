# Сайт Дмитрия Зимина

Статический сайт без сборки: `index.html`, `css/style.css`, `js/*.js`.

## Запуск локально

```
python3 -m http.server 8765
```
и открыть http://localhost:8765 (видео YouTube не играет при открытии файла напрямую через `file://`).

## Как править контент

Всё в `js/data.js` (шаблон со всеми полями — в комментарии в начале файла):
- `PERSON.contacts` — контакты (меню «Контакты», подвал, мобильное меню);
- `BIO` — биография, награды;
- `PRESS` — публикации (`id` используется для привязки к спектаклю);
- `WORKS` — все спектакли. Список «Постановки» в биографии строится из них автоматически,
  сгруппированный по `theatre` (порядок групп — массив `THEATRES`).

Главы на странице спектакля появляются, только если заполнены:

| Глава | Поле | Формат |
|---|---|---|
| Запись (плеер) | `videos` | `[{ id: 'YouTubeID', label: 'Акт I' }]` |
| О спектакле | `team` | `[['Художник', 'Имя']]` |
| Подробнее | `about` | любой текст; пустая строка — новый абзац; можно HTML |
| Актёры | `cast` | `[['Персонаж', 'Артист']]` |
| Галерея | `gallery` | пути к фото |
| Видео | `extras` | `[{ id: 'YouTubeID', title: 'Тизер' }]` — тизеры, пробы, репетиции |
| Публикации | `press` | id из `PRESS` |
| Файлы | `files` | `[{ title: 'Текст пьесы', url: 'assets/files/pesa.pdf' }]` или внешняя ссылка |

### Фото и обложка
1. Положить фото в `assets/perf/<slug>/` (лучше ~1600px по длинной стороне, JPG).
2. Прописать `gallery: ['assets/perf/<slug>/01.jpg', ...]`.
3. Обложка = `cover`, если указана; иначе кадр из видео; иначе первое фото галереи.

Сейчас у спектаклей с видео галерея — кадры из записи, у части спектаклей без видео — фото
из публикаций (`press-NN.jpg`, источник подписан под галереей).

## Английская версия
Переключатель RU/EN в шапке; английские адреса — `#/en/...`.
Все английские тексты — в `js/data-en.js` (по `slug` спектакля, `id` публикации).

### Страницы статей

Пересказы публикаций лежат в `js/press-texts.js` (по `id` публикации): `ru`/`en` — абзацы пересказа, `quotes` — короткие цитаты из оригинала с переводом, `archive` — ссылка на копию в Web Archive. Если для статьи есть запись, её заголовок в списках ведёт на страницу `#/press/<id>` с пересказом и ссылками на оригинал; если нет — сразу на сайт источника. Полные тексты статей не перепечатываются: они принадлежат авторам и изданиям.
Если поле не переведено, показывается русский вариант.

## Публикация (GitHub Pages)
Сайт выложен из ветки `main` (корень репозитория). Любой `git push` в `main` обновляет сайт через минуту-две.
После правок в файлах поднимайте версию `?v=N` в `index.html`, чтобы браузеры не брали старый кэш.

### Свой домен (необязательно, можно добавить позже)
1. Купить домен (например, `zimin.ru` или `dmitryzimin.com`).
2. У регистратора добавить DNS-записи:
   - для корня домена — четыре `A`-записи: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - для `www` — `CNAME` на `di-m-dy.github.io`.
3. В репозитории: Settings → Pages → Custom domain → ввести домен, включить «Enforce HTTPS».
